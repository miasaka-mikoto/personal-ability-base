# Windows shell scaffold

This directory is the first host boundary for a future Windows desktop shell.
It is intentionally dependency-free and inspectable:

- `run-dashboard.ps1` starts the local Node preview server.
- `run-dashboard.cmd` is the double-click equivalent for a developer checkout.
- `bridge-contract.json` records the future WebView2/Tauri host surface.
- the shell must provide a `window.PABCore` bridge before it is considered a
  native host; the source dashboard falls back to its offline adapter when the
  bridge is absent.

The scaffold is **not** a Windows installer, signed executable, updater, or
production sandbox. No `.exe` is generated by this repository yet. A future
WebView2/Tauri host will implement the bridge and keep Ability code outside
the host UI process, as described in `docs/platform-adapters.md`.

## Run the source preview

From a checkout on Windows PowerShell:

```powershell
.\platform\windows\run-dashboard.ps1
```

Then open `http://localhost:4173`. The launcher uses only Node.js 24+ and does
not download packages or contact GitHub.
